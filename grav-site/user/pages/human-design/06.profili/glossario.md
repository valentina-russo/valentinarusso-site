Il **Profilo** è una coppia di [Linee](/human-design/linee) scritta con una barra: 2/4, 3/5, 6/2. Nel **BG5 (Business Group 5)** si chiama **Profilo di Carriera**.

La **prima cifra** viene dal Sole della personalità: è la parte di te che riconosci, quella di cui sapresti parlare. La **seconda** viene dal Sole del design: agisce da sola, e di solito la vedono prima gli altri.

Le combinazioni possibili sono dodici, non trentasei: la meccanica del sistema lega le due righe secondo regole precise.

| Profilo | Nome | Nel BG5 |
|---|---|---|
| **1/3** | Investigatore / Martire | Funzione 1, Autorità + Funzione 3, Pioniere |
| **1/4** | Investigatore / Opportunista | Funzione 1, Autorità + Funzione 4, Influencer |
| **2/4** | Eremita / Opportunista | Funzione 2, Talento Naturale + Funzione 4, Influencer |
| **2/5** | Eremita / Eretico | Funzione 2, Talento Naturale + Funzione 5, Messaggero |
| **3/5** | Martire / Eretico | Funzione 3, Pioniere + Funzione 5, Messaggero |
| **3/6** | Martire / Modello di Ruolo | Funzione 3, Pioniere + Funzione 6, Leader |
| **4/6** | Opportunista / Modello di Ruolo | Funzione 4, Influencer + Funzione 6, Leader |
| **4/1** | Opportunista / Investigatore | Funzione 4, Influencer + Funzione 1, Autorità |
| **5/1** | Eretico / Investigatore | Funzione 5, Messaggero + Funzione 1, Autorità |
| **5/2** | Eretico / Eremita | Funzione 5, Messaggero + Funzione 2, Talento Naturale |
| **6/2** | Modello di Ruolo / Eremita | Funzione 6, Leader + Funzione 2, Talento Naturale |
| **6/3** | Modello di Ruolo / Martire | Funzione 6, Leader + Funzione 3, Pioniere |

## Come si legge nella tua carta

Il [calcolo gratuito](/calcolo-human-design) ti dà il Profilo già scritto, fra i dati di base.
